# Get Me Cab Dashboard

Modern cab management dashboard built with React, Vite, Tailwind CSS, and Recharts.

---

## Features

- Dashboard analytics
- Booking management
- Driver activity tracking
- Authentication system
- Protected routes
- Live statistics widgets
- Edit and delete bookings
- Search and filtering
- Responsive UI
- Modern dashboard design

---

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Recharts
- Axios
- Lucide React

---

## Installation

```bash
npm install
npm run dev
```
